# یاد (YAD) — نسخه‌ی اولیه‌ی قابل‌بازی

وب‌اپ آموزشی بازی‌محور ریاضی ششم دبستان. فارسی، راست‌به‌چپ، افقی ۱۶:۹، بدون سرور و بدون ثبت‌نام واقعی (همه‌چیز در `localStorage`).

## اجرا
```
npm install
npm run dev      # توسعه
npm test         # تست‌های منطق (۲۴ تست)
npm run build    # خروجی: پوشه‌ی dist (index.html تک‌فایلی + manifest، آیکون‌ها و sw.js برای نصب)
```

## چه چیزی ساخته شده
- **اسکلت کامل اپ:** ورود/پروفایل محلی، آواتار ماژولار (۴ شخصیت × ۸ رنگ × ۳ چشم × ۶ کلاه × ۴ اکسسوری × ۳ پشت‌بند، با قفل سطحی)، صفحه‌ی اصلی، نقشه‌ی سه دنیا، مأموریت‌های روزانه به تاریخ شمسی، سطح/تجربه/سکه/مدال، تنظیمات (کم‌کردن انیمیشن، تمام‌صفحه، شروع دوباره).
- **یک مرحله‌ی کامل: «فانوس‌های ممیز»** (فصل ۳، ص ۴۴ کتاب): ۳ درس تعاملی ← تمرین تطبیقی (۴ مهارت، ۵ نوع سؤال، ۳ سطح) ← نتیجه با ستاره و مدال ← چالش کارت‌های ممیز (ص ۴۵).
- **مرحله‌ی دوم: «پل کسر و اعشار»** (فصل ۳، ص ۴۵–۴۶): ۴ درس تعاملی (کسر↔اعشار، ساختن مخرج ۱۰/۱۰۰، ساده کردن، ممیز زیر ممیز) ← تمرین تطبیقی با ۴ مهارت: کسر به اعشار، اعشار به کسر یا عدد مخلوط (ساده‌شده)، شکل گسترده (کشیدن جمله‌ها)، جمع و تفریق ذهنی و ستونی. هر خطای رایج پیام تشخیصی دارد (مثلاً جای ممیز، ساده‌نشدن، هم‌تراز نکردن ممیزها).
- **نصب به‌صورت برنامه (PWA):** `manifest.webmanifest` با `display: fullscreen`، آیکون‌ها، و `sw.js` برای کار آفلاین. فقط روی https (یا localhost) نصب می‌شود.
- بقیه‌ی گره‌های نقشه (۶ + ۵ + ۵) عمداً «به‌زودی» هستند؛ عنوان و صفحه‌شان از فایل‌های فصل‌ها آمده.

## ساختار
```
src/stages/   defs.js (تعریف هر مرحله: مهارت‌ها، گرم‌کردن، تولید/ارزیابی، متن‌ها)
src/engine/   items.js (مرحله‌ی ۱) و bridge.js (مرحله‌ی ۲): تولید و ارزیابی سؤال، session.js (موتور تطبیقی)، words.js (خواندن اعداد)
src/lib/      decimal.js (اعشار دقیق، بدون float)، fa.js، jalali.js، store.js (وضعیت محلی)
src/data/     worlds.js (نقشه)، avatarItems.js، levels.js
src/components/  Models.jsx (مدل ۱۰۰تایی، نوار، شبکه‌ی رنگ‌آمیزی)، Keypad، ItemViews، BridgeViews، Learn، LearnBridge، Avatar، Scene
src/screens/  Intro, Setup, Home, Map, Wardrobe, Stage, CardsGame, Settings, LevelUp
tests/        logic.test.js
```

## افزودن مرحله‌ی جدید
1. در `data/worlds.js` گره را `ready: true` و `stageId` بده.
2. یک فایل مثل `engine/bridge.js` بساز: `SKILLS`، `makeItem`، `checkItem`؛ هر نوع سؤال = `generate` + `check` + یک View (مثل `BridgeViews.jsx`، و یک `case` در `ItemViews.jsx`).
3. مرحله را در `stages/defs.js` ثبت کن و درس‌ها را به `SCENES` در `screens/Stage.jsx` اضافه کن.
موتور تطبیقی (`session.js`) به نوع محتوا وابسته نیست و تعریف مرحله را می‌گیرد.
در متن‌های بازخورد، کسر را به‌شکل `{۷|۱۰}` بنویس تا کسرِ عمودی نمایش داده شود و با ممیز («/») اشتباه نشود.

## تصمیم‌های محصولی که گرفته شد
- بافت مسئله‌ها داستان فانتزی است، ولی عددها و ساختار ریاضی همان کتاب است.
- تمرین‌های بازپاسخ کتاب («توضیح دهید»، «مسئله طرح کنید») به انتخاب/مرتب‌سازی تبدیل می‌شوند.
- هیچ تایمری وجود ندارد؛ پاداش بر پایه‌ی درست‌شدن و پشتکار است نه سرعت.
- خواندن عدد اعشاری مطابق کتاب: «شصت و هشت عدد صحیح و نوزده صدم».

- نصب روی گوشی: بعد از قرار دادن پوشه‌ی `dist` روی یک میزبان https، میان‌بر قدیمی صفحه‌ی اصلی را پاک کن و دوباره «افزودن به صفحه‌ی اصلی» بزن؛ تا manifest نباشد، فقط یک میان‌بر مرورگر ساخته می‌شود.
